# 新版工作空间与项目归档

登录后选择“我的项目”或“加入小组”。入口页没有侧栏，使用帮助位于两个模块下面靠右。进入项目等后续操作页，侧栏继续保留。

“我的项目”显示自建项目和审核通过后加入的小组项目。没有项目时，只突出创建项目按钮；“加入小组”页没有已加入项目时显示“暂无项目”。每张项目卡标明创建时间和最后更新，后者取最近一次项目操作记录，没有操作记录则使用创建时间。一个项目对应一个协作小组，本次没有引入另一套小组结构。

## 随时保存整个项目

进入项目侧栏的“项目归档”，点击“下载项目快照 ZIP”。负责人或复核者可以在任何进度下保存，包括尚未定稿的轮次和空项目。

快照包含材料、编码规则、成员编码、协商结论和修改记录。它不会结束编码或锁住批次。草稿和提交状态保留；尚未完成的协商结论放在 `05_adjudication`，正式定稿放在 `06_final`。ZIP不包含账号密码、邀请密钥或服务器密钥，不是服务器备份，也不能直接一键恢复。

## 只导出需要的编码记录

1. 在“自定义归档导出”选择编码员范围。普通成员只能选择本人；负责人和复核者可选择全部编码员。
2. 输入关键词。快速搜索匹配包含关键词的内容，精确搜索匹配完整文字。需要按文件、批次、代码、状态、组别或时间筛选时，展开“更多筛选条件”。组别等附加字段按原文件的字段名和对应值填写。
3. 点击“筛选 / 预览”。查看命中数量、原文、来源、组别、代码和保存状态。
4. 选择导出范围：“全部匹配”包含所有页；“前 N 条”取最近保存的 N 条；勾选行会自动切换为“本页勾选”，只导出当前页所选记录，跨页不保留勾选。
5. 选择 Excel、CSV、TSV 或 JSON，点击“导出编码记录”。一次最多50000条，需要更多时按文件、批次或时间分批。

改变筛选条件后，先重新预览再导出，防止显示的结果和实际范围不一致。每行对应一名编码员的一个已保存编码单元，不是未经保存的输入；“已提交”不等于已经多人协商定稿。拆分后的各单元有自己的编码，但原时间、组别和其他附加字段保留。默认不重复导出拆分前原记录，需要留存旧记录时选择“包含已拆分的原记录”。

## 编码工作台

前后上下文默认各显示两条。点“查看上文 +3”或“查看下文 +3”继续查看，始终限定在同一来源文件和上下文分组内。

“确认并下一条”和“保存草稿”位于“我的编码”顶部，矮屏和手机使用固定操作区。选择主代码后可以点击；清空后重新禁用。也保留“无适用代码”和“不确定”判断，不确定时需先填写原因。提交成功后才进入下一条；保存失败、版本冲突时不会擅自覆盖或丢弃输入。
