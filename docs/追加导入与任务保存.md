# 追加导入与任务保存

## 下一条和保存任务

编码中点击“下一个”，先提醒可以选填跳过原因；再次点击同一个按钮，保存草稿并进入对应下一条。不要求先选主代码，也不会算作已确认。

到最后一个单元仍可点“下一个”。平台检查本人本批次的未完成数，选择“继续未完成单元”可回到尚未确认的任务；“保存任务”先确认当前草稿保存成功，再回到“我的项目”，不是导出或归档。保存失败会留在原页面。全部完成时显示绿色完成提示。

项目卡片显示“我的编码 · 批次名”和已确认数/总数。只看本人当前批次，不累加重复轮次、不混入同伴答案；草稿不算完成，被拆分替代的原任务不重复计数。

## 追加材料

项目进行中可继续在“材料”上传文件，预览后确认。导入结果显示新增单元和跳过重复记录的数量。

- 相同原文＋全部原始附加字段相同：跳过，保留原记录、原编码和历史。
- 只是语句相同，但时间、编号、小组、说话人或其他字段不同：正常新增。
- 字段顺序和文件名不影响判断；不忽略文本空格、不做语义相似匹配。
- 本次文件内部的完全重复记录也会跳过。已拆分、已排除记录不会因为重导入重新生成原单元。
- TXT没有其他字段，相同文本行会被视为重复。相同语句确实发生多次时，使用带原始编号或时间等字段的CSV/Excel表。

原文件仍保留。新增单元进入项目材料库，不自动改变已安排的任务或已归档的批次。

## 补充编码规则

再次导入默认补充当前编码本，保留已有规则；完全重复的代码跳过，同一代码标识但名称、定义、例子、层级等不同的会要求核对，不静默覆盖。需要修改旧规则，直接在“编码规则”中编辑。

如果全部重复，保留原编码本，不增加空版本。当前编码本已用于任务时，补充规则会保留更新前的历史；只有主动同步的已有批次才使用新规则，原判断仍保留。高级设置仍允许明确选择另存为整份新规则。
