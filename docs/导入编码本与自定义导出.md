# 导入编码本与自定义导出

已有规则不用再一条条录入。先上传文件，核对读取的内容，确认后即可安排使用这些规则的新任务。导出可以按后续分析需要选择格式和列，不改变平台中的数据。

## 导入编码本

1. 打开项目的“编码本与版本”，点击“导入编码本”。负责人和复核者可以导入。
2. 选择文件：Excel XLSX、CSV、TSV、Word DOCX、TXT、Markdown、JSON或文字型PDF。Excel有多个工作表时可以切换。
3. 查看内容并对应字段。每条代码必须有标识、名称和定义。中文、英文列名都可以手动对应，常见列名会自动尝试识别。
4. 选择导入方式。独立新版本只包含本次文件中的代码，旧版本保留；追加草稿保留已有代码，不覆盖重复标识。冻结版本不能追加。
5. 核对完整预览。超过20条可以翻页。没有确认前不会写入编码本。
6. 勾选已核对，点击“确认导入并使用”。到“安排编码任务”选择导入后的版本。旧轮次不会自动换规则。

### 文件怎么整理

表格第一行是表头，一行一条代码。至少提供这三列，名称不同也可以上传后对应：

| key | name | definition |
| --- | --- | --- |
| PLAN | 计划 | 为后续活动确定目标、顺序或职责 |

可选列：`parent_key`、`include_when`、`exclude_when`、`positive_example`、`negative_example`、`boundary_example`、`coexist_priority`、`color`。上级填代码标识，不填名称。上级和下级在文件中可以任意排序。

Word可以使用具有字段表头的规则表格，或按下面的字段块书写。TXT、Markdown、文字型PDF中的规则块也需要明确字段名：

```text
代码标识：PLAN
代码名称：计划
定义：为后续活动确定目标、顺序或职责。
适用条件：明确提出接下来要做什么。
正例：我们先列目标，再分工。

代码标识：CHECK
代码名称：检查
定义：对照目标检查进度或结果。
```

空行分隔不同代码，一条代码内部的多行定义连续书写。Markdown另支持普通竖线表格。合并单元格、复杂排版建议整理为Excel。

导入页有Excel、Word、CSV、TXT和JSON模板。源码中`examples/codebook.csv`和`examples/codebook.txt`是虚构示例，不是你的正式研究规则。

### 保护措施和限制

代码重复、必填项缺失、上级不存在或层级循环时，会提示原因，不会只导入一半。代码标识最长40字，名称100字，定义和各说明5000字。每批最多8MB、1000条代码。预览24小时内有效，过期需要重新上传；暂存原件目前不自动定期清理。

确认导入后保留原文件、字段对应、来源工作表和操作历史，完整项目归档包含已确认的导入原件。未确认预览不进入研究归档。Office宏、危险XML和过大的解压内容会被拒绝；Excel公式按文字读取，不执行。

旧版DOC、XLS先另存为DOCX、XLSX。PDF仅解析可读取的文字规则块，不保证任意PDF表格能直接还原。扫描件、加密PDF、复杂表格请转换为文字表格或Word原件。PDF解析有时间、内存及页数限制，含无文字页会提醒核对。平台不会把普通论文自动推断成编码本，也不调用AI或外部服务。

## 自定义导出

1. 点击项目左侧的“导出中心”，或者编码本、工作台中的导出入口。
2. 选择编码本、材料、我的独立编码、全员独立编码、分歧清单或最终定稿。需要时选具体版本或轮次，点击“显示导出选项”。
3. 选择Excel、CSV、TSV或JSON；编码本还可以选Word。
4. 默认全部字段都勾选，可以直接下载。要自定义，就取消不需要的字段，修改列名和顺序数字。列名和顺序不能重复。CSV还可选择分隔符、UTF-8或GB18030。
5. 点击“下载导出文件”，保存到浏览器的下载位置。

自定义是调整导出内容，不是任意改扩展名。后缀由实际格式自动确定。目前不保存个人导出方案，下次导出需重新选择。

独立阶段只能下载自己的答案；全员判断和分歧遵守原有协商开放条件。最终数据必须完成定稿归档。导出最终结果不会改变个人独立答案。

CSV和TSV会给可能被当成公式的文字加安全前缀；Excel按文本保存，JSON保留原文及数值、布尔类型。Excel不支持的控制字符或超过单元格32767字的内容会提示改用JSON或CSV，不删除、不截断原文。每次最多50000行、300列，更大项目按轮次或编码员分批。

编码本导出后可以在其他项目重新导入。建议保留标准列名及标识、名称、定义、上级代码；删掉必要字段后只能作为局部记录，不能直接重建完整规则。

导出不是整个服务器备份。完整研究档案仍在“项目概览”，账号和数据库备份仍用原来的备份操作。
